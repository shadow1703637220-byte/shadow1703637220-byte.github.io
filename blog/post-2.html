5 分钟搭好你的第一个个人博客

2026-10-13 科技教程 约 3 分钟读完

想拥有一个自己的博客，但一想到"买服务器、搭后端、配数据库"就劝退？好消息：纯静态托管就能搞定一切，免费、快速、几乎不用维护。下面三步，5 分钟上线。

一、准备：一个 GitHub 账号

去 github.com 注册个账号（免费）。GitHub Pages 会为你提供免费的静态网站托管，这就是我们博客的"服务器"。

二、三步上线

  1. 建仓库：新建一个名为 你的用户名.github.io 的公开仓库。
  2. 传文件：把写好的 index.html 上传到仓库根目录（网页端点 Add file → Upload files 就行，不用命令行）。
  3. 开 Pages：仓库 Settings → Pages → Source 选 main 分支，保存。等 1～2 分钟，访问 你的用户名.github.io 就能看到你的博客了。

三、（可选）绑定自己的域名

如果你有域名，在仓库根目录加一个 CNAME 文件，里面只写你的域名（一行），再去域名商那里加一条 CNAME 解析到 你的用户名.github.io，HTTPS 会自动配好。

结语

你看，没有服务器、没有数据库、没有一行后端代码，博客就上线了。剩下的就是最重要的事：开始写第一篇文章。工具永远只是起点，内容才是博客的灵魂。
