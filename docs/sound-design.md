# 交互音效

参考站：https://krishnagupta.web.app/
公开音效脚本：https://krishnagupta.web.app/sound.js
检查日期：2026-11-05

已将原站公开脚本保存为 `krishna-sound.reference.js`，便于研究和试听。该快照仅作参考，不被页面导入，也不进入 Vite 构建。没有发现脚本中的 MP3/WAV 音效资源；这些声音由 Web Audio 振荡器、滤波噪声、包络、混响和声像实时合成。原脚本未附许可证声明。

原站包含 tick / hover / tap、open / close、flip / flick、success / notify、key、whoosh 等通用声音；还有木头、塑料、金属、玻璃、纸张碰撞以及相机、翻书、茶杯等物品音色。`window.sound.play(name, { x })` 是原站通用播放接口；`impact`、`pickup`、`voice`、`ruffle` 对应碰撞、拿起物品、合成人声和摩擦。

本站 `sound.js` 使用独立的简化音频引擎，参考其频率变化和短促质感，降低整体音量，使用短包络而不增加混响资源。无需下载音频或请求参考站。

| 交互 | 音色 |
| --- | --- |
| 章节导航悬停 / 点击 | 三角波拨弦 / 双音拨弦，每个章节对应不同音高 |
| 四张作品卡片悬停 / 打开 | 玻璃泛音 / 玻璃与拨弦叠加，四张卡片各有固定音高 |
| 菜单展开 / 收起 | 低频上扬气流 / 下落气流 |
| 关于按钮 | 木质轻敲 / 低频柔和收束 |
| 列表 / 网格切换 | 单次机械卡位 / 两段机械卡位 |
| 文章、便签、图片翻页 | 短纸张摩擦 / 较长翻纸 |
| 照片与头像窗口 | 机械双击 / 相机快门 |
| 终端悬停 / 打开 | 短方波 / 复古双音开机 |
| 终端输入 / 退格 / 执行 / 未知命令 | 带轻微音高变化的键声 / 擦除声 / 回车确认 / 下行双音 |
| 桌面窗口拖动后放下 | 便签为纸张、头像为木质、终端为低沉敲击 |
| 联系按钮 / 社交链接 | 上扬气泡 / 三音和弦 / 发送滑音 |
| 地球点击、下拉选择地区 | 雷达定位双音 |
| 整理桌面 | 上扬双音 |
| 联系方式复制成功 | 两音确认，仅在剪贴板成功后播放 |

悬停按区域使用不同音色，并共享 110ms 节流，防止快速扫过时声音堆叠。作品和导航的音高固定，键盘和落点仅作小幅随机变化。语义动作优先，避免普通点击音盖住回车确认、复制结果和弹窗关闭声。

默认允许音效，浏览器首次真实点击或按键后才初始化 AudioContext；加载和自动视图切换不发声。开关位于右下角，并在模态窗口内提供同样的控制。偏好写入 `aven-sound`，支持跨标签页同步；存储不可用时在当前页面仍可使用。静音与隐藏页面会停止当前声音，隐藏页面暂停音频上下文。移动端不触发 hover；减少动态效果设置下关闭声柱闪动。每个临时音源结束后断开节点。
