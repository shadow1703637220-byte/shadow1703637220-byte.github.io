# Elliot Hu 个人站观察与适配

参考：https://elliothu.me/ 。通过浏览器查看首页、关于区、项目目录和桌面控件，保存了桌面截图，并检查了 Terminal 入口。在线站展示了系统菜单栏、Dock、复古电脑、播放器、照片、手写标记、彩色项目分组和留言区域。其公开 GitHub 仓库的 Next.js 结构与当前在线资源并不相同，不能把仓库视为在线版本的完整源码。

本次采用“电脑桌面中的个人物件”这一交互方向，在关于与作品之间新增 `#desk` 创作桌面。实现位于 `creative-desktop.js` / `creative-desktop.css`，使用原生 JavaScript 独立编写，内容和头像来自 Aven 现有资料。

- 半透明 Dock：六个真实入口，指针靠近时邻近图标逐渐放大，键盘聚焦也有反馈。
- 终端、便签、头像三个窗口：标题栏拖动、边界约束、焦点置顶、关闭与重新打开、一键整理。标题栏支持方向键移动，Shift 加速。
- 终端命令：`help`、`whoami`、`work`、`about`、`blog`、`contact`、`home`、`notes`、`clear`。支持上下键历史，输出使用 textContent，不执行输入的代码。
- 便签纸、低饱和渐变、手写弧形下划线和少量贴纸呼应参考站视觉，并使用本站蓝金色系。
- 手机使用纵向窗口布局，关闭窗口后可从 Dock 重新打开并定位；减少动态效果时关闭 Dock 缩放。
- 创作桌面区域内收起原章节导航，避免遮挡 Dock。`#desk` 接入原有站内转场，支持深链接。

浏览器已验证拖动、键盘移动、窗口收起与恢复、命令输出和历史、命令跳转、原作品详情返回、375 / 390 / 900px 无横向溢出以及减少动态效果模式。

## 2026-11-05 模块衔接调整

再次检查在线页面和公开 bundle `assets/index-D7-58UOE.js`：章节导航调用 `scrollIntoView({ behavior: 'smooth', block: 'start' })`，首页使用平滑滚动归位；菜单项有 100ms 背景色过渡，局部尺寸动画可见 stiffness 360 / damping 36 的弹簧配置，以及 160ms 的透明度过渡。这里记录的是可观察实现，不把整站动画都归为同一组参数。

本站适配：

- 同页章节使用 360–900ms 的连续滚动，实际时长随距离变化；可以被新目标、滚轮、触摸和滚动键立即打断，不锁住页面。连续点击采用最新目标。
- 保留项目详情页的独立转场，覆盖与揭开共 620ms，删除中间停顿，内容入场距离由 90px 降为 24px。
- 作品预览缓存每个项目的面板，160ms 内容淡入淡出；跨越卡片间隙保留 110ms，位置按帧平滑跟随且贴近视口边缘时连续限位，不再突然翻到鼠标另一侧。滚动、切页和失焦立即清理。
- 插画悬停不再修改正在运行的动画周期，避免摆动相位突变；改为轻微缩放。
- 磁吸按钮填色从当前动画位置反向过渡，快速重入不从头播放。桌面窗口使用 160ms 收起、260ms 恢复，可中断恢复。
- 章节滚动期间保留底部导航，避免经过桌面时突然消失；导航关闭函数仅在状态真正变化时移动焦点。

验证：桌面连续点击、滚轮打断、作品浮层复用与滚动清理、项目进入/返回、桌面收起/恢复、减少动态效果；390px 触屏菜单导航、浏览器前进后退和横向溢出检查均通过，未出现浏览器运行错误。构建通过。

## 录屏中的滚动衔接

根据用户提供的 12.4 秒录屏，补上滚动驱动的场景变化：首屏构图随滚动缩小、淡出，后续内容从左右归位。

- `hero.js`：首屏在粘性区前 62% 的滚动距离内，从 scale 1 缩到 .72，同时透明度从 1 降到 0；介绍文字从左侧、头像从右侧逐渐进入。ViewTimeline 显式设置零 inset，避免导航的 scroll-padding 让首屏在顶部就开始淡出。不支持 ViewTimeline 时，使用暂停的 Web Animation 按滚动位置设置 currentTime，得到相同结果。
- `scroll-scenes.js`：关于区、桌面窗口、作品、足迹、文章和相册按视口位置进入；多列按左右分组，单列交替方向。顶部从视口 97% 移到 57% 时完成入场；停止滚动即停在当前位置，上滚沿原路径恢复。手机缩短横向距离。
- 使用独立的 translate 属性，保留桌面拖动的 transform；替换原先一次触发的向上淡入。聚焦时显示完整内容；减少动态效果时取消这些动画。布局变化和作品列表/卡片切换会更新位置。

验证：Chrome 原生时间轴与禁用 ViewTimeline 的回退结果一致；首屏缩放、透明度及反向滚动，作品左右方向、中途位置和归位均通过。390px 手机各区域无横向溢出；动态切换减少运动、桌面键盘移动及收起/恢复、作品列表/卡片切换和详情进入/返回正常，未出现运行错误。
