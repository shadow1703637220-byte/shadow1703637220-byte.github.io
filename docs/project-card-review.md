# 文件夹卡片与星空清晰度更新

依据用户提供的 17.3 秒参考录屏，采用文件夹轮廓、持续左右摆动的独立插画、悬停变深色，以及鼠标附近弹出动态缩略图四个行为。四个插画使用原创 SVG，不依赖位图放大。沿用站内项目详情和双入口列表切换，默认显示卡片。

内容工场与 Aven 个人站使用其公开页面的浏览预览，每段 6 秒，无音轨，悬停静音循环播放，退出暂停。Token 管理器目前只有 GitHub 个人主页入口，小程序尚未提供公开演示，二者使用标注「交互示意」的 CSS 动画。视频加载或播放失败也退回示意，并更新标题，避免错误显示「实站录屏」。

星空图片使用本轮用户附件中的横版原图 1672 × 941。此前竖版图宽度仅 700px，横屏裁切放大是模糊的主要原因。第二轮性能优化已移除首屏 Canvas，直接显示原始 PNG，使用静态 SVG 银河和淡出／位移过渡展示介绍，保留分步入场与反向滚动还原。当前实现与性能数据见 `performance-review.md`。

卡片更新时已通过 Chrome 检查：四项预览逐一显示与退出、两段视频真实播放、弹层边缘约束、作品详情与返回、列表切换、375 / 390 / 900px 触控布局无横向溢出、减少动态效果。第二轮性能优化再次检查真实视频、详情与返回、2× DPR 首屏画面、首屏过渡与反向滚动，以及 390px 手机原生时间轴与回退模式。动画预览使用 textContent 标注，示意与实录区分。
