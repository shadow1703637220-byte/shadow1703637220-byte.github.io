# Aven溺心海 · 个人主页使用说明

这个网站是纯静态的，改完提交后 1～2 分钟自动上线。所有操作都在 GitHub 网页端完成。

## 文件是干嘛的

| 文件 | 作用 | 你要改什么 |
|---|---|---|
| `index.html` | 网页的全部文字和结构 | 改名字、简介、项目、联系方式都在这里 |
| `css/style.css` | 全部样式（颜色、排版、动画） | 换主题色只改文件顶部 `:root` 里的颜色值 |
| `js/main.js` | 滚动叙事、悬停特效 | 一般不用动；想调放大强度看文件里的 ★ 注释 |
| `blog/` | 博客文章，每篇一个 HTML 文件 | 新文章让我帮你生成，你只管发文字 |
| `assets/` | 放图片的文件夹 | 头像、项目截图放这里 |

> 页面里所有要改的地方都标了 `★ 在这里改` 的中文注释，对着改就行。

## 怎么改文字

1. 打开仓库 → 点开 `index.html` → 右上角 ✏️（铅笔）编辑
2. 找到 `★ 在这里改` 的注释，按说明改文字
3. 点 **Commit changes** → **Commit changes**，等 1～2 分钟刷新网站看效果

## 怎么换头像

1. 进 `assets` 文件夹 → **Add file** → **Upload files**，上传你的头像，命名为 `avatar.jpg`
2. 打开 `index.html`，找到"换头像"那段注释，按说明把占位圆圈换成图片那行
3. Commit，刷新看效果

## 怎么加新项目

1. 在 `index.html` 的作品区，复制任意一个 `<article>...</article>` 整块
2. 粘贴到它的后面，改标题、简介、标签、链接
3. Commit

## 怎么换主题色

打开 `css/style.css`，只改最顶部 `:root` 里的 `--accent`（主色）和 `--accent2`（副色），比如换成粉色 `#f472b6`。

## 怎么发博客文章

1. 把文章文字（标题+正文）发给我
2. 我按网站版式排好，生成 `blog/` 下的新页面并推上去
3. 我会在首页"博客"区自动加上这篇文章的卡片

## 怎么加好物推荐

1. 把产品名、一句话卖点、购买链接发给我
2. 我做成推荐卡片推上去（链接会带 `rel="sponsored"` 标记，这是联盟链接的规范做法）

## 发布 / 预览

- 每次 **Commit changes** 后等 1～2 分钟
- 打开 https://nixinhai.de5.net，按 **Ctrl+F5**（Mac 是 Cmd+Shift+R）强制刷新看最新效果
- 这就是预览，不需要别的操作

## 注意事项

- 不要删除 `CNAME` 文件（如果有），它是绑定你域名的，删了网站地址会失效
- 图片建议压缩到 500KB 以内，手机加载更快
- 所有外部链接都用 `https://` 开头
